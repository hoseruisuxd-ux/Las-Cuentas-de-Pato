# 🦆 Las Cuentas de Pato

**Las Cuentas de Pato** es una aplicación móvil para Android diseñada a medida para optimizar y agilizar la gestión de pedidos y las cuentas de un negocio local de comida enfocado en un grupo selecto de clientes habituales.

Nació con un propósito claro y práctico: llevar el control diario directamente en el celular, reemplazando las libretas y notas manuales para evitar errores de cálculo, ahorrar tiempo en la atención y mantener un registro claro de los pedidos y saldos de cada cliente.

## 🚀 Características Principales

* **Gestión de Clientes Selectos:** Registro organizado de los clientes habituales del negocio para llevar un historial claro de sus consumos.
* **Control de Pedidos y Cuentas:** Cálculo rápido y sin errores de los totales a pagar por cada orden o acumulado.
* **Portabilidad Total (Android):** Pensada para usarse cómodamente desde el teléfono móvil durante la jornada de trabajo, sin necesidad de computadora ni conexión compleja.
* **Transparencia y Orden:** Facilita la revisión de cuentas pendientes y pagos realizados de manera visual y directa.

## 🛠️ Desarrollo y Tecnologías

* **Plataforma:** Android (distribuida como archivo `.apk`).
* **Google AI Studio:** Apoyo en la lógica de desarrollo, estructuración y asistencia con inteligencia artificial.

## 📲 Instalación (Android)

1. Descarga el archivo `.apk` desde la sección de **Releases**.
2. En tu dispositivo Android, abre el archivo descargado.
3. Si el sistema lo solicita, habilita la opción **"Instalar aplicaciones de orígenes desconocidos"** para tu navegador o gestor de archivos.
4. Completa la instalación y abre **Las Cuentas de Pato**.

## 💡 El Origen del Proyecto

Este proyecto surgió de una necesidad real en casa: facilitar el trabajo diario de mi mamá en su emprendimiento gastronómico. Lo que empezó como una solución para dejar atrás las cuentas en papel se convirtió en una app móvil funcional que demuestra cómo la tecnología puede resolver problemas cotidianos de los pequeños negocios.
